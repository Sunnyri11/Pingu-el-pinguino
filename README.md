# Pingüi · Portal de videojuegos

Portal web con dos videojuegos hechos en Unity, ejecutados dentro de la misma página.

- `pingu-navidad/` → Juego 1: Pingüi · Navidad (build WebGL)
- `pingu-pacman/`  → Juego 2: Pingüi · Laberinto del Polo Norte, estilo Pac-Man (build WebGL; súbelo con ese nombre de carpeta)

Cada juego tiene su botón START y no arranca hasta que se pulsa.
Asignatura: Game Development · Univalle
